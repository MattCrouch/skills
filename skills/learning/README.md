# Learning

Skills for reading and learning.

| Skill | Description |
|---|---|
| [reading-digest](reading-digest/SKILL.md) | Digest shared material — summarize a link or document, distill it into key takeaways, and check the user's own understanding against the source. Use whenever a URL/article/document is shared (even a bare link), when the user offers their own summary or notes to verify, or when checking for connections to earlier material. |
