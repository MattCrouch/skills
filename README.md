# My skills

Personal agent skills shared across machines and projects.

## Installation

### Claude Code

```bash
/plugin marketplace add your-github-username/skills
/plugin install <skill-name>@matt-skills
```

## Cursor

```bash
cp -r skills/engineering/<skill-name> .cursor/skills/
```

## Skills

### Engineering

- [review-pr](skills/engineering/review-pr/SKILL.md) — Reviews the current branch like a PR — intent, approach, and actionable feedback. Use when reviewing PRs or branches, a PR URL or number, summarizing changes, or seeking feedback before opening or merging.

### Learning

- [reading-digest](skills/learning/reading-digest/SKILL.md) — Digest shared material — summarize a link or document, distill it into key takeaways, and check the user's own understanding against the source. Use whenever a URL/article/document is shared (even a bare link), when the user offers their own summary or notes to verify, or when checking for connections to earlier material.
