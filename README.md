# My skills

Personal agent skills shared across machines and projects.

## Installation

### Claude Code

```bash
/plugin marketplace add your-github-username/skills
/plugin install <skill-name>@matt-skills
```

## Cursor

```bash
cp -r skills/engineering/<skill-name> .cursor/skills/
```

## Skills

### Engineering

- [review-pr](skills/engineering/review-pr/SKILL.md) — Reviews the current branch as a pull request — explains what it accomplishes, its approach, and senior-developer code review feedback with improvement suggestions. Use when the user asks to review a PR, review the current branch, summarize branch changes, explain what a branch is trying to do, or wants senior dev feedback before opening or merging a PR.
