# My skills

Personal agent skills shared across machines and projects.

## Installation

### Claude Code

```bash
/plugin marketplace add your-github-username/skills
/plugin install <skill-name>@matt-skills
```

## Cursor

```bash
cp -r skills/engineering/<skill-name> .cursor/skills/
```

## Skills

### Engineering

- [review-pr](skills/engineering/review-pr/SKILL.md) — Reviews the current branch like a PR — intent, approach, and senior dev feedback. Use when reviewing PRs or branches, summarizing changes, or seeking feedback before opening or merging.
